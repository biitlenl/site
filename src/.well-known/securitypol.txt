========= biitle.nl Security Policy =========

We do not have the funds to have a bug bounty
program, but if you want to report a bug to any
of our projects (fluidserver, etc) then you can
do so at:

for low severity bugs (e.g. possible crash in
very specific, uncommon scenario): go to the
project's bug tracker

for high severity bugs (e.g. RCE): shoot an
e-mail to contact@biitle.nl. make sure your
message starts in [SECURITY <project_name>],
replacing <project_name> with the project
name.

example:

Title: [SECURITY FluidServer] RCE in vX.X.X

Bla bla bla, RCE, Bla bla bla, triggered by
sending X to Y, etc........................

I will read your message very fast probably.

Make sure you include the most details you
can in your message, and how to cause the
bug.

Only send me an e-mail if it's really really
important. If it's not a security risk, send
it to the issues on GitHub.
