
# biitle.nl

This is the webpage for biitle.nl, built with Astro.js.

## Contributing

1. Fork this repo and clone it by running `git clone --recurse-submodules https://github.com/biitlenl/site`.
2. Start your web server and run `npm run dev`.
3. Commit your work: `git commit -am "Message"`
4. Push your work: `git push origin your/branch`
5. Now, create a PR on the branch you modified.
